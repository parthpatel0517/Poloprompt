FAQ: Social Caption & Hook Prompts

          

            Why does the tool ask for 3 hook options instead of just one?
            
The hook — the first line viewers see or hear — is the single biggest factor in whether someone stops scrolling. Different angles (a bold claim, a relatable pain point, a curiosity gap) resonate with different audiences, so generating multiple distinct options gives you a genuine choice to A/B test rather than committing to the AI's first guess. The prompt also includes a worked example and a ban on overused caption clichés like "unlock" and "it's giving ___," which is what typically separates a hook that sounds like a real creator wrote it from one that reads as obviously AI-generated — a plain "write me an Instagram caption" prompt has no such guardrails.

          

          

            Why do captions need different formatting for each platform?
            
Each platform's algorithm and audience behavior rewards different caption styles. LinkedIn audiences read longer, value-driven posts with line breaks, while X favors short, punchy statements with minimal hashtags. TikTok and Reels captions support the video rather than replacing it, so they stay short and casual. Using the wrong length or hashtag convention for a platform can quietly hurt reach even when the content itself is good, so this tool bakes platform norms directly into the prompt.

          

          

            How does the "Goal" selection change the output?
            
The goal you choose determines what the call-to-action at the end of the caption asks the viewer to do. A "Grow Followers" goal produces a follow-focused CTA, while "Drive Website Clicks" produces a link-focused CTA, and so on. Matching your CTA to your actual goal (instead of using a generic "check it out!") measurably improves conversion on the action you actually care about.

          

          

            Can I use the same prompt for multiple posts on the same topic?
            
You can, but for best results run it once per platform since the caption length and hashtag conventions differ. If you're repurposing one piece of content across several platforms, generate a separate prompt for each one rather than copying a single caption everywhere — audiences can tell when a caption clearly wasn't written for the platform they're on.

          

          

            Is this tool free, and is my post topic stored anywhere?
            
Yes, it's completely free with no account needed. The prompt is built entirely in your browser with JavaScript — nothing you type is sent to a server or saved. Generate as many caption prompts as you like.
